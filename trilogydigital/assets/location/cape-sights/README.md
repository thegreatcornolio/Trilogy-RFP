# Cape Town sights photos

Used by the **Sights in and around Cape Town** collage in `trilogydigital/index.html` (`#cape-sights-collage`).

## How to add photos

1. Drop image files into this folder (`trilogydigital/assets/location/cape-sights/`).
2. Prefer short lowercase filenames, e.g. `table-mountain.jpg`, `waterfront.jpg`, `chapmans-peak.jpg`.
3. Formats: JPG or WebP. Aim for ~1200–1600px on the long edge (not multi-MB phone originals).
4. Tell the agent (or commit + push) once the files are here — the collage markup will be wired to whatever you upload.

## Suggested mix

A good collage wants variety: landscape hero shots, a couple of portrait/tall frames, and a few detail/lifestyle tiles. No captions required on the images themselves.
