# Client insights documents

Used by the RFP Builder section **Why we want to work with you** (`section-21`).

## How to upload (per client)

1. Open the [RFP Builder](../rfp-builder/).
2. Add **Why we want to work with you** from the section library (and put it where you want in the proposal order — usually after Executive Summary).
3. In **Editable placeholders**, use **Upload insights document**.
4. Choose the client’s insights file (**PDF, DOCX, TXT or Markdown**).
5. Review / edit the two scraped boxes:
   - **Why we want to work with you**
   - **Your potential pain points**
6. Preview / Final commit as usual.

Each new upload re-scrapes and overwrites those two boxes (you can still edit afterwards).

## How to label the document

Use clear headings so the scraper can split the content, for example:

```text
Why we want to work with you
- Reason one
- Reason two

Your potential pain points
- Pain point one
- Pain point two
```

Also recognised (case-insensitive): headings containing `pain points`, `potential challenges`, `why we want to work`, `why Trilogy`, `reasons we want`, etc.

If no pain-points heading is found, the full document lands under reasons and the pain-points box stays empty for manual paste.
